# shop-test 项目知识库（示例）

本目录下 Markdown 会被 **AI RAG** 读取：启动后建索引，对话时按问题检索相关片段注入模型上下文。

**说明**：你在后台「菜单管理」里新增或调整的菜单，会以 **当前登录角色可见菜单树** 的形式从数据库注入 AI（优先于本文件）。本 Markdown 用于补充说明、业务文档；二者可同时存在。

## 如何维护

- 在此目录增加、修改 `.md` 文件后，**重启后端** 以重建索引（当前实现为启动时一次性加载）。
- 内容尽量分主题写清标题，便于分块检索。

## 菜单速查（与默认初始化菜单一致）

- **打包插件**：`插件系统` → `打包插件`
- **插件市场**：`插件系统` → `插件市场`
- **插件安装**：`插件系统` → `插件安装`
- **代码生成器**：`系统工具` → `代码生成器`
- **服务器状态**：顶级菜单 `服务器状态`

## 业务说明（请按实际项目改写）

- shop-test 基于 gin-vue-admin 的后台管理系统。
- 具体业务模块以左侧菜单与数据库配置为准。
